Landing Page — Etran

Адаптивный лендинг финтех-сервиса, свёрстанный на чистом HTML и CSS (без препроцессоров и фреймворков).

О проекте

Это мой первый самостоятельный проект по вёрстке. Я делал его, чтобы закрепить базовые навыки работы с HTML/CSS: адаптивную сетку, BEM-нотацию в классах, работу с SVG-иконками, кастомные CSS-переменные и медиа-запросы.

Проект ещё находится в процессе доработки — часть багов уже найдена и исправляется, что-то предстоит доделать позже.

Стек
HTML5
CSS3 (Flexbox, Grid, CSS Custom Properties)
Адаптивная вёрстка (clamp(), относительные единицы)
Без сборщиков и фреймворков
Структура проекта
├── css/
│   ├── blocks/       # стили отдельных блоков (header, hero, footer и т.д.)
│   ├── global/        # общие стили (reset, переменные, шрифты, типографика)
│   └── style.css      # главный файл, импортирующий все остальные
├── fonts/
├── images/
├── js/
├── index.html
└── script.js
Известные ограничения

Так как это учебный проект, в коде ещё встречаются недочёты — например, невалидные значения некоторых CSS-свойств, дублирующиеся правила и не до конца доведённая адаптивность на отдельных экранах. Работа над исправлениями продолжается.
